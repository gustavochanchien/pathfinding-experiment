Technical Overview

1. Replicating Albuquerque

This simulation constructs a graph network of Albuquerque using live OpenStreetMap (OSM) data via the Overpass API.

It parses raw vector nodes to differentiate between Residential (Green) and Commercial (Blue) zones, generating agents with specific home/work coordinates. Need to add the university and maybe some other zones.

2. Traffic Physics (Spatial Hashing)

We use a Spatial Hash Grid to track agent density. If multiple agents occupy the same grid cell, a "Congestion Penalty" is applied to their speed.

Current Setting: 1% Slowdown per neighbor. Higher numbers creates emergent traffic jams on main arteries and intersections.

3. Visualizing Algorithms

Yellow Tendrils: Represent the "Search Space"—the nodes the algorithm considered in memory before finding a solution.
Cyan/Green Lines: The final calculated path.

Tip: Lower the population to < 10 to see the "Thinking Process" in slow motion.

4. Batching & Departure

To simulate rush hour, we use Synced Departure. Agents calculate paths asynchronously (background) but wait in a "Ready" pool. They are released in Batches to create waves of traffic, rather than a steady trickle.
